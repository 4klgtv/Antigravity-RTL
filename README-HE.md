# כבידה פרסית (Persian Gravity) 🚀

כלי אוטומטי ליישור מימין לשמאל (RTL) והחלת גופן "וזירמאטן" עבור אפליקציית הפיתוח Antigravity ועורכי הקוד המובילים (VS Code, Cursor, Trae, VSCodium, Windsurf).

> 🟢 **נבדק ואושר בגרסאות:** `macOS 15.7.3 (Sequoia)` ו-`Antigravity v2.6.0` (בהצלחה מלאה)

## 🛠️ תכונות הפרויקט
- **החלת יישור מימין לשמאל (RTL) ב-Antigravity**: יישור אוטומטי של חלונית הצ'אט, התפריטים והלוחות הכלליים.
- **התקנת גופן אוטומטית**: הורדה והתקנה ישירה של הגופן Vazirmatn בספריית הגופנים של מערכת ההפעלה.
- **הגדרת עורכי הקוד**: עדכון קובצי ההגדרות של עורכי הקוד לעבודה עם הגופן Vazirmatn ב-Antigravity, VS Code, Cursor, Trae, VSCodium, ו-Windsurf.
- **תמיכה בריבוי מערכות הפעלה**: סקריפטים מותאמים ל-macOS, Windows ו-Linux.

## 🚀 התקנה בקליק אחד
להתקנת הגופן והחלת התיקון, הפעל את הסקריפט המתאים למערכת שלך:
- **macOS**: הורד והפעל את הקובץ [`setup_vazirmatn.command`](./setup_vazirmatn.command)
- **Windows**: הרץ את הקובץ [`setup_vazirmatn.ps1`](./setup_vazirmatn.ps1) באמצעות PowerShell
- **Linux**: הרץ את הקובץ [`setup_vazirmatn_linux.sh`](./setup_vazirmatn_linux.sh)
